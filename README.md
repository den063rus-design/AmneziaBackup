# AmneziaBackup

Комплект создаёт защищённые архивы данных OpenVPN и AmneziaWG из Docker-контейнеров Amnezia VPN для миграции на Debian 12/13. Он не копирует Docker `overlay2`, старый IP, firewall или маршруты.

## Установка

Скопируйте эти четыре файла на сервер и выполните:

```bash
sudo bash install.sh
```

Будут установлены `/opt/AmneziaBackup/backup.sh` и `restore.sh`, а каталоги и скрипты получат права `700`.

## Резервная копия

```bash
sudo /opt/AmneziaBackup/backup.sh
```

Архив и его SHA256 находятся в `/opt/AmneziaBackup/backups/`; перенесите оба файла на новый сервер защищённым способом. Он содержит данные протоколов и диагностические сведения Docker, но не Docker image snapshots и не `overlay2`.

## Миграция и восстановление

1. На новом Debian 12/13 установите Docker и через обычное приложение Amnezia VPN разверните Self-hosted сервер с OpenVPN и нужной, совместимой версией AmneziaWG.
2. Узнайте старые порты из архива, не распаковывая секретные данные:

   ```bash
   tar -xOf /opt/AmneziaBackup/backups/amnezia-backup-*.tar.gz ./MANIFEST.txt | grep 'ports:'
   ```

   AmneziaWG и OpenVPN могут получать случайные порты при первоначальной установке. До восстановления задайте в приложении Amnezia ровно старый порт и тот же TCP/UDP транспорт OpenVPN. Скрипт покажет несовпадение и ничего не изменит, если они различаются.
3. Скопируйте архив в `/opt/AmneziaBackup/backups/`, затем запустите `sudo /opt/AmneziaBackup/restore.sh` или передайте путь к архиву.
4. Перед изменениями создаётся `pre-restore-*.tar.gz` для отката. Старый внешний IP не переносится. Если клиенты используют домен, переключите его DNS на новый IP после успешного восстановления.
5. Проверьте подключение несколькими существующими OpenVPN и AWG-конфигурациями. Ключи и peer'ы не перевыпускаются.

При несовместимости `amnezia-awg` и `amnezia-awg2` обычное восстановление намеренно прекращается: сначала разверните на новом сервере совместимый вариант протокола через приложение Amnezia.
